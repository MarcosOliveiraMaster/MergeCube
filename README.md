# Cubo 3D Interativo

## Como usar
1. Abra `index.html` no navegador.
2. Arraste o cubo com o mouse para girar.
3. Use a roda do mouse para zoom.
4. Use os controles inferiores para alterar o tamanho e a distância da câmera.
5. Para usar uma arte própria/autorizada, coloque seis imagens em `assets/` e altere os `background` das seis faces em `style.css`.

## Estrutura
- `index.html` — estrutura da página
- `style.css` — visual e geometria CSS 3D
- `script.js` — rotação, zoom, tamanho e reset
- `assets/` — local para as seis artes autorizadas

Observação:
O PDF fornecido contém uma obra protegida por direitos autorais e informa expressamente que a transformação/modificação do material não é autorizada. Por isso, este pacote entrega o motor interativo sem incorporar a arte do PDF.
